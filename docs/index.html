Features

核心能力

不是单个提示词模板，而是一套可复用的配图生产流程。

📐

场景自动定比例

小红书 3:4｜公众号封面 21:9、正文 16:9｜纯 PPT 16:9。明说→直接用；可推断→复述确认；未说明→询问。

🎨

10 种风格 · 25+ 布局

奶油纸手绘、社论全景、小红书卡通、奶油手账……每种附风格锁定模板；对比、流程、循环、鱼骨、冰山等布局按内容自动匹配。

🔌

生图通道自动判定

宿主内置生图（Codex / 网页版 GPT、Gemini）→ MCP 生图工具 → API 兜底（火山 Ark Doubao Seedream / Gemini 3 Pro Image），能不依赖 API 就不依赖。

🧭

5 阶段配图流程

需求澄清 → 配图规划 → 风格选择（阻塞确认）→ 文案定稿 → 提示词封装；另有 PPT 大纲快速通道，3 阶段直达批量提示词。

🔤

排版硬约束

全图字体最多 2 种，层级靠字号、字重与颜色深浅区分；大字号、少字短句，所有中文清晰可读——杜绝密集小字。

📖

拼版交付 PDF / HTML

小红书与 PPT 场景生成 ≥2 张后，一键拼成自包含 PDF / HTML（图片 base64 内嵌、双击即开），缺压缩依赖时优雅降级。

Workflow

普通配图 · 5 阶段

风格选择是强制阻塞点——展示 10 种风格，必须等用户明确选择才继续。

1

需求澄清

内容 / 场景 / 受众 / 字多字少，产出一句话复述

2

配图规划

拆内容定图清单：几张、每张讲啥、用啥布局

⚠️ 强制阻塞
2.5

风格选择

展示 10 种风格表，等用户明确选择后锁定

3

文案定稿

逐字定稿「图上写什么」，作为唯一真值

4

提示词封装

文案封装成独立代码块的可复制提示词

⚡ PPT 快速通道 P1解析确认 P2风格配色 P3批量生成提示词 适用于已含布局 + 文案的完整大纲，全部 16:9

Quick Start

快速开始

给四项就能开始：① 要配图的内容 ② 场景 ③ 受众 ④ 少字清爽 or 信息密度。API 通道可直接跑脚本。

生成图片 · 火山 Ark Doubao Seedream 
# 快版（~30s/张），适合批量配图
python scripts/generate_image.py \
  --prompt "星际穿越，黑洞，复古列车，电影大片感" \
  --model "doubao-seedream-5-0-260128" --size "2K"

# 提示词文件批量生图 + 自动插入文章
python scripts/generate_image.py \
  --prompts-file "./wechat/12_prompts.md" \
  --out-dir "./wechat/13_images/" \
  --insert-into "./wechat/11_final_final.md"
编辑 / 多图合成 · Gemini 3 Pro Image 
# 单图编辑
python scripts/generate_image.py --provider gemini \
  --prompt "给这只猫加上墨镜" --input-image ./cat.png --output ./cool-cat.png

# 多图合成（最多 14 张）
python scripts/generate_image.py --provider gemini \
  --prompt "把这些合成为一个场景" \
  --input-image img1.png --input-image img2.png --output ./combined.png
拼版交付 · 自包含 PDF / HTML 
# 小红书竖版合集（图片 base64 内嵌，双击即开）
python3 scripts/generate_html.py ./my_images 输出名

# PPT 横版（每页一张，contain 不裁切）
python3 scripts/generate_html.py ./my_images 演示 --orientation landscape
